多平台媒体下载器（Windows）使用说明
====================================

支持：Instagram、小红书、抖音、YouTube
内容：图片、视频、Reels、Shorts、图文作品、播放列表
画质：网站当前向你的账号和地区提供的最高可用画质

一、使用方法

1. 请先把整个 ZIP 压缩包解压，不要在压缩包预览里直接运行。
2. 双击“Start Downloader.cmd”。
3. 第一次打开会自动准备下载组件，通常需要一两分钟。
4. 选择你平时已经登录网站的浏览器。
5. 粘贴作品链接，按回车开始下载。

下载位置：

  你的用户文件夹\Downloads\媒体下载

二、第一次运行

程序需要 Python 3.9 或更高版本。如果电脑没有 Python，会优先尝试用
Windows 自带的软件安装工具自动安装；如果没有成功，会打开 Python 官方
下载页面。完成 Python 安装后，重新双击启动文件即可。

三、浏览器提示

需要登录才能查看的内容，请先在 Chrome、Edge 或 Firefox 中登录对应网站，
再在下载器中选择同一个浏览器。运行下载时，建议先关闭该浏览器，以免
浏览器锁定 Cookie 文件而导致读取失败。

四、常见问题

- 如果文件显示为 M4S：新版会自动合并或转换为通用 MP4。
- 如果下载失败：确认链接是单个作品链接、浏览器已登录且账户可正常查看。
- 如果窗口一闪而过：右键“Start Downloader.cmd”，选择“以管理员身份运行”后重试。
- 如果杀毒软件提示：本工具是公开源码脚本，没有数字签名；你可以在 GitHub
  仓库中查看全部源码。请只从本项目官方 Release 下载。

五、使用责任

请只下载自己拥有、获授权保存或法律允许下载的内容，并遵守网站服务条款、
版权规定和所在地法律。付费、DRM、已删除、过期或地区受限内容可能无法下载。
